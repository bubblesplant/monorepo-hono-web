# 01 - 初始化项目

## 1.1 创建目录并初始化

```bash
mkdir C:/Users/malei/Desktop/hono/src
cd /c/Users/malei/Desktop/hono
pnpm init
```

## 1.2 安装依赖

```bash
# 运行时依赖
pnpm add hono @hono/node-server @hono/zod-validator zod ioredis argon2

# 开发依赖
pnpm add -D tsx typescript @types/node
```

依赖说明：

| 包 | 用途 |
|---|---|
| `hono` | Web 框架本体 |
| `@hono/node-server` | Node.js 适配器（`serve()` 启动 HTTP 服务） |
| `@hono/zod-validator` | zod 校验中间件 `zValidator` |
| `zod` | schema 定义 |
| `ioredis` | Redis 客户端（会话存储） |
| `argon2` | 密码哈希 |
| `tsx` | 开发期直接跑 TypeScript |

## 1.3 package.json

把 `package.json` 整体替换为：

```json
{
  "name": "hono-server",
  "version": "0.1.0",
  "private": true,
  "type": "module",
  "scripts": {
    "dev": "tsx watch src/main.ts",
    "start": "tsx src/main.ts",
    "typecheck": "tsc --noEmit"
  },
  "dependencies": {
    "@hono/node-server": "*",
    "@hono/zod-validator": "*",
    "argon2": "*",
    "hono": "*",
    "ioredis": "*",
    "zod": "*"
  },
  "devDependencies": {
    "@types/node": "*",
    "tsx": "*",
    "typescript": "*"
  }
}
```

## 1.4 tsconfig.json

在根目录新建 `tsconfig.json`：

```json
{
  "compilerOptions": {
    "target": "ES2022",
    "module": "ESNext",
    "moduleResolution": "bundler",
    "strict": true,
    "exactOptionalPropertyTypes": true,
    "noUncheckedIndexedAccess": true,
    "skipLibCheck": true,
    "esModuleInterop": true,
    "forceConsistentCasingInFileNames": true,
    "useUnknownInCatchVariables": true,
    "verbatimModuleSyntax": true,
    "types": ["node"],
    "baseUrl": ".",
    "paths": {
      "@/*": ["src/*"]
    },
    "outDir": "dist",
    "noEmit": true
  },
  "include": ["src"]
}
```

> `@/*` 路径别名需要在运行时生效，tsx 原生支持 tsconfig paths，无需额外配置。

## 1.5 .env

根目录新建 `.env`：

```bash
PORT=3000
HOST=0.0.0.0
REDIS_URL=redis://localhost:6379
SESSION_TTL_SECONDS=604800
```

> `SESSION_TTL_SECONDS=604800` 即 7 天滑动过期。
