# 01 - 初始化与依赖

## 1.1 注册 catalog 依赖

monorepo 用 pnpm catalog 统一管理版本。编辑根目录 `pnpm-workspace.yaml`，在 `catalog:` 段的 `@fastify/static` 一行后面加：

```yaml
  '@hono/node-server': ^1.19.6
  '@hono/swagger-ui': ^0.5.2
  '@hono/zod-openapi': ^1.1.4
  hono: ^4.10.4
```

## 1.2 创建目录

```bash
cd D:/web/stu/bubbles/bubblesjs/packages/create-bubbles/template-vp-monorepo-react-nestjs
mkdir -p apps/server-hono/src/{config,common/errors,common/http,common/access,db,modules/auth,modules/access,modules/companies}
```

## 1.3 package.json

新建 `apps/server-hono/package.json`：

```json
{
  "name": "server-hono",
  "version": "0.0.1",
  "private": true,
  "type": "module",
  "license": "UNLICENSED",
  "scripts": {
    "dev": "vp run --watch src/main.node.ts",
    "dev:bun": "bun --watch run src/main.bun.ts",
    "start": "vp run src/main.node.ts",
    "test": "vp test",
    "format": "vp fmt",
    "typecheck": "tsc --noEmit",
    "db:push": "drizzle-kit push",
    "db:generate": "drizzle-kit generate",
    "db:migrate": "drizzle-kit migrate",
    "db:studio": "drizzle-kit studio"
  },
  "dependencies": {
    "@hono/node-server": "catalog:",
    "@hono/swagger-ui": "catalog:",
    "@hono/zod-openapi": "catalog:",
    "argon2": "catalog:",
    "dotenv": "catalog:",
    "drizzle-orm": "catalog:",
    "hono": "catalog:",
    "ioredis": "catalog:",
    "pg": "catalog:",
    "shared": "workspace:*",
    "zod": "catalog:"
  },
  "devDependencies": {
    "@types/node": "catalog:",
    "@types/pg": "catalog:",
    "drizzle-kit": "catalog:",
    "typescript": "catalog:",
    "vite-plus": "catalog:"
  }
}
```

> `vp run` 是 vite-plus 的 TS 运行器（根 `vite.config.ts` 已开启 `run.cache`）。`--watch` 参数如与所装版本不一致，运行 `vp run --help` 确认。

## 1.4 tsconfig.json

新建 `apps/server-hono/tsconfig.json`（对齐 Nest 版约定，去掉装饰器）：

```json
{
  "extends": "../../tsconfig.base.json",
  "compilerOptions": {
    "target": "ES2023",
    "module": "NodeNext",
    "moduleResolution": "NodeNext",
    "types": ["node"],
    "isolatedModules": true,
    "esModuleInterop": true,
    "noEmit": true,
    "noUncheckedIndexedAccess": true,
    "exactOptionalPropertyTypes": true,
    "paths": {
      "@/*": ["./src/*"]
    }
  },
  "include": ["src/**/*.ts", "*.config.ts"],
  "exclude": ["node_modules", "dist"]
}
```

## 1.5 vite.config.ts

新建 `apps/server-hono/vite.config.ts`（与 Nest 版同构）：

```ts
import { resolve } from 'path'
import { defineConfig } from 'vite-plus'

export default defineConfig({
  resolve: {
    alias: {
      '@': resolve(__dirname, 'src'),
    },
  },
  test: {
    environment: 'node',
    include: ['test/**/*.spec.ts'],
    restoreMocks: true,
  },
})
```

## 1.6 drizzle.config.ts

新建 `apps/server-hono/drizzle.config.ts`：

```ts
import { defineConfig } from 'drizzle-kit'

export default defineConfig({
  dialect: 'postgresql',
  schema: './src/db/schema.ts',
  out: './drizzle',
  dbCredentials: {
    url: process.env.DATABASE_URL ?? 'postgres://postgres:postgres@localhost:5432/server_hono',
  },
})
```

## 1.7 .env 与环境变量加载

新建 `apps/server-hono/.env`：

```bash
PORT=3001
HOST=0.0.0.0
DATABASE_URL=postgres://postgres:postgres@localhost:5432/server_hono
REDIS_URL=redis://localhost:6379
SESSION_TTL_SECONDS=604800
```

新建 `src/config/env.ts`：

```ts
import 'dotenv/config'

/** 集中读取环境变量，业务代码不直接碰 process.env。 */
export const env = {
  port: Number(process.env.PORT ?? 3001),
  host: process.env.HOST ?? '0.0.0.0',
  databaseUrl:
    process.env.DATABASE_URL ?? 'postgres://postgres:postgres@localhost:5432/server_hono',
  redisUrl: process.env.REDIS_URL ?? 'redis://localhost:6379',
  sessionTtlSeconds: Number(process.env.SESSION_TTL_SECONDS ?? 60 * 60 * 24 * 7),
} as const
```

## 1.8 安装

```bash
cd D:/web/stu/bubbles/bubblesjs/packages/create-bubbles/template-vp-monorepo-react-nestjs
pnpm install
```

> `shared` 是 workspace 包，如果还没构建过，先在 `packages/shared` 跑一次 `pnpm build`（`vp pack`），否则 `import 'shared/types'` 找不到 dist。
