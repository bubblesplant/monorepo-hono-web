# 07 - 启动与验证

## 7.1 启动

```bash
# 基础设施（如未启动）
docker run -d -p 5432:5432 -e POSTGRES_PASSWORD=postgres --name hono-pg postgres:16
docker run -d -p 6379:6379 --name hono-redis redis:7
docker exec -i hono-pg createdb -U postgres server_hono

# monorepo 根目录
pnpm install
pnpm --filter shared build        # 首次需要，构建 workspace 共享包

# server-hono
cd apps/server-hono
pnpm db:push                       # 建表
pnpm dev                           # Node 入口，默认 3001 端口
# 可选双平台验证：
pnpm dev:bun                       # Bun 入口（需本机已装 Bun）
```

看到 `[node] server listening on http://localhost:3001` 即成功。

## 7.2 逐场景验证

### ① 健康检查（公开）

```bash
curl -s http://localhost:3001/health
# {"ok":true}
```

### ② Swagger UI

浏览器打开 `http://localhost:3001/api-docs`，应看到 auth / companies 两组接口。

### ③ 未登录访问受保护接口 → 401 + Bearer 质询

```bash
curl -si http://localhost:3001/auth/me
```

预期：

```
HTTP/1.1 401 Unauthorized
WWW-Authenticate: Bearer realm="api"
x-request-id: <uuid>

{"code":"AUTH.SESSION_TOKEN_MISSING","message":"缺少有效的登录 Token"}
```

### ④ 参数校验失败 → 400 + details

```bash
curl -s -X POST http://localhost:3001/auth/register \
  -H 'Content-Type: application/json' \
  -d '{"account":"ab","password":"123"}'
```

预期 `COMMON.VALIDATION_FAILED` + `details` 列出 account/password 两个字段错误。

### ⑤ 注册 → 登录 → 携带 token 访问

```bash
curl -s -X POST http://localhost:3001/auth/register \
  -H 'Content-Type: application/json' \
  -d '{"account":"demo001","password":"password123"}'
# {"token":"<TOKEN>"}

TOKEN=<返回的 token>
curl -s http://localhost:3001/auth/me -H "Authorization: Bearer $TOKEN"
# {"user":{"userId":"...","sessionId":"..."}}
```

### ⑥ 权限不足 → 403

```bash
COMPANY_ID=$(python -c "import uuid;print(uuid.uuid4())")
curl -s http://localhost:3001/companies/$COMPANY_ID/members -H "Authorization: Bearer $TOKEN"
# {"code":"ACCESS.FORBIDDEN","message":"没有权限执行此操作"}
```

给用户授权（SQL 直插，教学用）：

```bash
docker exec -i hono-pg psql -U postgres -d server_hono -c \
  "INSERT INTO access_grants (user_id, permission)
   SELECT id, 'company.member.read' FROM users WHERE account='demo001';"
```

重试 → 200。

### ⑦ 登出 → token 立即失效（服务端吊销）

```bash
curl -s -X POST http://localhost:3001/auth/logout -H "Authorization: Bearer $TOKEN" -o /dev/null -w '%{http_code}\n'
# 204
curl -s http://localhost:3001/auth/me -H "Authorization: Bearer $TOKEN"
# {"code":"AUTH.SESSION_INVALID","message":"登录已失效，请重新登录"}
```

### ⑧ 404 同构

```bash
curl -s http://localhost:3001/no-such-route
# {"code":"COMMON.NOT_FOUND","message":"请求的资源不存在"}
```

## 7.4 验收清单

- [ ] 所有错误响应都是 `{code, message, details?}` 结构
- [ ] 401 响应带 `WWW-Authenticate: Bearer realm="api"`
- [ ] 所有响应带 `x-request-id`
- [ ] 控制台只在 5xx 时输出 `http_request_failed`，且无 token/密码明文
- [ ] Swagger UI 可浏览全部接口
- [ ] Node 入口全部场景通过；Bun 入口至少 register/login/me 通过（验证 argon2）
